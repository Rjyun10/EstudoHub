# 📚 EstudoHub

O **EstudoHub** é uma plataforma web completa voltada para estudantes, projetada para centralizar ferramentas de produtividade, organização acadêmica, controle financeiro e interação social em um só lugar.

---

## 🚀 Funcionalidades

* **📱 Feed de Estudos:** Espaço interativo para compartilhar resumos, publicações e interagir com outros estudantes, contando com barra de pesquisa dinâmica.
* **🎉 Mural:** Mural de recados e avisos importantes.
* **🌐 Comunidade (Social):** Conecte-se com colegas e compartilhe conhecimento.
* **⏱️ Timer & Foco:** Ferramenta baseada em técnicas de concentração para otimizar o tempo de estudo.
* **🔢 Calculadora de Médias:** Calculadora prática para acompanhar o desempenho acadêmico.
* **📊 Planejador Financeiro:** Simulador de investimentos e controle de metas de renda para organizar as finanças pessoais.
* **📝 Criação de Notas:** Editor dedicado para anotar ideias e matérias importantes.
* **🎨 Sistema de Temas Dinâmico:** Alternância entre múltiplos temas visuais (Azul Acadêmico, Dark Mode, Roxo Tecnológico, Verde Foco, Cyberpunk, entre outros).

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando tecnologias web fundamentais, sem necessidade de instalações complexas de frameworks pesados:

* **HTML5 / CSS3** (Com variáveis customizadas para o sistema de temas)
* **JavaScript (Vanilla ES6+)** para manipulação de DOM e lógica interativa
* **Bootstrap 5** para estilização de componentes, grid e layout responsivo
